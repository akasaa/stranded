# Stranded

Demo arcade (Tugas Portfolio #2), gaya Duck Hunt, 2D dengan kesan kedalaman. Dibuat dengan Godot 4.7.2 (renderer GL Compatibility).

Berburu mahluk terbang dengan kekuatan di tangan, isi bar lapar sampai penuh sebelum 6 tenaga habis. 5 level dengan kesulitan naik.

## Menjalankan
1. Buka Godot 4.7.2, klik **Import**, pilih `project.godot`.
2. Tekan **F5**. ESC untuk keluar.

Semua visual masih placeholder yang digambar lewat kode (`main.gd`). Angka level ada di konstanta `LEVELS`.
